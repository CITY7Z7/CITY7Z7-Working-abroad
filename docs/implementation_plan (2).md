# CITY7Z7-Working-abroad: Комплексное техническое задание (ТЗ) на модернизацию

Масштабное обновление и переработка архитектуры полевого ассистента для работы и жизни за рубежом: превращение приложения в полноценный рабочий инструмент с удобным стартовым хабом заметок, визуальным Markdown-редактором, оптимизированным ядром документов и визиток, корректными системными отступами и модулем загрузки/парсинга актуальных справочников.

---

## Подтверждённые решения и выбор пользователя

> [!IMPORTANT]
> **Ключевые решения, зафиксированные по итогам обсуждения и опроса:**
> 1. **Стартовый экран при входе**: Полный список всех заметок с поиском по заметкам, фильтрами/сортировкой (закрепленные вверху) и крупной кнопкой создания новой заметки.
> 2. **Обновление справочников и базы знаний**: 
>    - Прямой импорт локальных файлов `.md`, `.txt` и `.json` с интеллектуальным автопарсингом и раскладкой по странам/рубрикам.
>    - Онлайн-синхронизация по URL (загрузка актуальных датасетов из веб-источников).
>    - Встроенный веб-парсер по списку ссылок, сохраняющий выжимки прямо в локальную базу данных.
> 3. **Модель безопасности (Selective Zero-Trust)**:
>    - Строго изолированная зона: «Мой профиль» и «Документ-хаб» (паспорта, контракты, конфиденциальные файлы) не имеют доступа к сети, ничего не передают вовне и хранятся в зашифрованном виде.
>    - Для остальных модулей (справочники, курсы, шаблоны, заметки, веб-парсер) активирован доступ в Интернет (`android.permission.INTERNET`).
> 4. **Снятие запрета скриншотов**: Убран глобальный `FLAG_SECURE` с главного окна, пользователь может свободно делать скриншоты экрана.
> 5. **Тема оформления по умолчанию**: Светлая тема (`LIGHT`) при первом запуске приложения.
> 6. **Порядок бокового меню**: 
>    - 1-й блок: **Заметки**
>    - 2-й блок: **Общие инструменты** (Калькулятор, Разговорник, Словарь, Шаблоны писем, Контакты, QR-визитка, Журнал)
>    - 3-й блок: **Разделы стран** (Ирландия, Германия, Нидерланды и др.)
> 7. **Экстренная кнопка SOS (112)**: Убрана навязчивая красная плашка из главного меню; вызов перенесён в Настройки и контекстное меню помощи.
> 8. **Имя скомпилированного пакета**: Приложение именуется `CITY7Z7-Working-abroad` (в `build.gradle.kts`, `strings.xml`, `metadata.json`).

## 1. Концепция и функциональные требования

### 1.1 Хаб заметок и визуальный Markdown-редактор
- **Главный экран заметок**:
  - Карточки заметок с заголовком, датой изменения, превью текста и бейджами («Закреплено», «Заблокировано от редактирования», «Приватная»).
  - Быстрый поиск по заголовкам и содержимому заметок.
  - Кнопка создания новой заметки (`FAB` / верхняя панель).
- **Экран заметки (редактор / просмотр)**:
  - Кнопка **Сохранить** с визуальным статусом («Сохранено»).
  - Кнопка **Закрепить** (Pin / Unpin).
  - Кнопка **Заблокировать от изменений** (Read-only lock): защищает заметку от случайного ввода и редактирования, пока пользователь явно не снимет замок.
  - Кнопка переключения **Просмотр / Редактор**.
  - Кнопка **Копировать текст** в буфер обмена одним кликом.
  - Кнопка **Удалить заметку** с обязательным диалогом подтверждения и возможностью отмены (Snackbar «Отмена» 5 сек).
  - **Вставка изображений**: возможность прикреплять и отображать картинки в тексте заметки (локальные медиа через Photo Picker / SAF и отображение через Coil).
  - **Визуальная панель Markdown-форматирования**: ряд кнопок над клавиатурой (Заголовки H1–H3, Жирный `**`, Курсив `*`, Чек-лист `- [ ]`, Список `- `, Нумерованный `1. `, Таблица, Цитата `> `, Код, Разделитель `---`).

### 1.2 Исправление просмотра документов (PDF, изображения, таблицы)
- **Устранение черного фона в PDF**:
  - Перед отрисовкой страницы через `PdfRenderer.Page.render` выделенный `Bitmap` принудительно очищается белым цветом (`bitmap.eraseColor(android.graphics.Color.WHITE)`).
  - Фон подложки страницы переводится в чистый светлый цвет с аккуратной тенью и масштабированием (Zoom & Pan).
- **Таблицы CSV / XLSX**:
  - Четкие заголовки столбцов, чередование строк, плавная горизонтальная и вертикальная прокрутка.

### 1.3 Оптимизация QR-визитки и персональной карточки
- **Оптимизация рендеринга**:
  - Отказ от синхронной генерации матрицы 512x512 на главном потоке и от 260 000 вызовов `drawRect` в Canvas.
  - Генерация чистой битовой матрицы минимального размера (модули QR ~29–35 точек) в фоновом потоке (`Dispatchers.Default`) и мгновенная отрисовка через кэшированный `Bitmap` с фильтрацией ближайшего соседа (`FilterQuality.None`). Мгновенный отклик (< 30 мс).
- **Связь персональной карточки с системой**:
  - Расширенная карточка в «Мой профиль»: ФИО (рус / лат), телефон, email, профессия, локальный адрес, налоговый номер (PPS/Steuer-ID), IBAN/банк, контакт для экстренной связи.
  - Автоматическая подстановка этих данных в QR-визитку (vCard 3.0), шаблоны официальных писем и формы обращений.

### 1.4 Сквозной глобальный поиск
- Восстановление и запуск полнотекстового поиска (FTS4):
  - Поиск по всем статьям справочника, терминам словаря, фразам разговорника, шаблонам писем и заметкам.
  - Вывод сгруппированных результатов с быстрым переходом к нужному разделу.

### 1.5 Наполнение справочника стран и контекстные инструменты
- **Разделение контента по странам**:
  - Ирландия: английский/ирландский контекст, PPS, Revenue, WRC, RTB, 112/999.
  - Германия: немецкий язык в разговорнике, Steuer-ID, Anspruchnahme, Bürgeramt, Krankenkasse, 112/110.
  - Нидерланды: нидерландский язык, BSN, DigiD, Belastingdienst, IND, 112.
- **Исправление навигации по разделам**:
  - Клик по разделам («Статус», «Работа», «Налоги», «Жильё», «Медицина») открывает полноценный список статей соответствующей рубрики, а не статичную карточку страны.
- **Пользовательские шаблоны писем**:
  - Готовые письма (запрос жилья лендлорду, обращение в налоговую, уведомление работодателя).
  - Возможность создавать, редактировать, сохранять собственные шаблоны и копировать готовый текст с подставленными персональными данными.

### 1.6 Модуль загрузки и парсинга знаний (Knowledge Importer & Web Parser)
- **Импорт файлов**:
  - Кнопка в Настройках / Справочнике: «Загрузить файл знаний (.md, .txt, .json)».
  - Парсер разбирает структуру документа (метаданные `--- country: de, section: tax ---` либо заголовки первого/второго уровня `# Германия -> ## Налоги`) и сохраняет статьи в SQLite.
- **Синхронизация по URL**:
  - Ввод URL-ссылки на файл каталога или JSON/MD-репозиторий и фоновая загрузка с обновлением базы.
- **Встроенный веб-парсер**:
  - Список проверенных официальных ссылок с возможностью добавления пользовательских URL.
  - Извлечение основного текста и сохранение в рубрику страны без необходимости запуска сторонних серверов.

### 1.7 Системные отступы (Edge-to-Edge)
- Добавление `Modifier.safeDrawingPadding()` / `systemBarsPadding()` во всех корневых контейнерах, исключающее перекрытие статус-бара Android (часы, уровень заряда батареи, Wi-Fi).

## 3. План реализации по шагам

1. **Базовая конфигурация и безопасность:**
   - Настройка имени выходного артефакта `CITY7Z7-Working-abroad` в `app/build.gradle.kts` и `strings.xml`.
   - Добавление `android.permission.INTERNET` в `AndroidManifest.xml` для веб-парсера и онлайн-синхронизации.
   - Удаление принудительного `FLAG_SECURE` в `MainActivity.kt`.
   - Установка светлой темы (`LIGHT`) по умолчанию.
   - Добавление отступов `safeDrawingPadding()` в `SplitViewRoot` для защиты часов и системных индикаторов.

2. **Заметки — главный экран и визуальный редактор:**
   - Перевод стартовой навигации на `Selection.NotesHub`.
   - Создание экрана списка заметок (`NotesListScreen`) с фильтрами, сортировкой и поиском.
   - Добавление кнопок в `NoteEditorScreen`:
     - Сохранить
     - Закрепить (Pin)
     - Заблокировать от изменений (Lock Read-only)
     - Переключение Просмотр / Редактор
     - Копировать текст
     - Удалить с диалогом подтверждения
   - Внедрение визуальной панели форматирования (H1-H3, Bold, Italic, Checkbox, List, Table, Image picker).
   - Поддержка вставки и отображения локальных изображений в теле заметки.

3. **Реорганизация боковой навигации и SOS:**
   - В `LeftNavigationPane.kt` перестроить порядок: Заметки -> Общие инструменты -> Разделы стран.

   - В `DocumentHubViewModel.renderPdfPage` добавить `bitmap.eraseColor(android.graphics.Color.WHITE)` перед рендерингом для предотвращения черного фона.
   - Оптимизировать генерацию QR: перенести построение матрицы в фоновый поток с компактным размером, отрисовывать через кэшированный Bitmap без подвисаний.
   - Расширить персональную карточку в `ProfileScreen` и связать её с шаблонами и vCard.

5. **Полнотекстовый поиск и навигация по разделам:**
   - Исправить маршрутизацию по клику на разделы стран (открытие списка статей соответствующего раздела).
   - Запустить сквозной поиск через FTS с экраном результатов поиска.

6. **Контент и шаблоны писем:**
   - Наполнить разделы для Ирландии, Германии, Нидерландов реальной полезной информацией.
   - Добавить локализованные разговорники и словари терминов для каждой страны.
   - Реализовать интерактивный модуль шаблонов писем (создание, редактирование, копирование с автозаполнением данных).

7. **Модуль импорта знаний и веб-парсер:**

8. **Сборка, верификация и обновление документации:**

- [ ] Приложение компилируется успешно с именем `CITY7Z7-Working-abroad`.
- [ ] При старте приложения открывается список заметок, а интерфейс не перекрывает системные часы и статус-бар.
- [ ] По умолчанию включена светлая тема.
- [ ] Скриншоты работают штатно.
- [ ] В заметках доступны все кнопки: Сохранить, Закрепить, Заблокировать, Редактор/Просмотр, Копировать, Удалить с подтверждением, Markdown-тулбар и вставка изображений.
- [ ] Боковое меню упорядочено: Заметки -> Общие инструменты -> Разделы стран; красная кнопка SOS убрана из главного меню.
- [ ] PDF-документы отображаются с нормальным белым фоном и четким черным текстом.
- [ ] QR-код генерируется мгновенно без подвисаний интерфейса.
- [ ] Поиск по системе находит статьи, заметки и термины.
- [ ] Разделы стран наполнены и открывают реальные статьи; разговорники и словари индивидуальны для стран.
- [ ] Работает загрузка файлов MD/JSON и веб-парсер.
- [ ] `README.md` обновлен в соответствии с требованиями.
